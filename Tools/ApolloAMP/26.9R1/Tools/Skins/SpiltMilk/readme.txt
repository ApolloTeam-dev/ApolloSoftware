SPILT MILK 

Designed by: Cameron Kerr

For use in Winamp 5.xx

Version 1.2 25/02/2004
Winamp 5 version!
Added video.bmp gen.bmp and gen_ex.bmp So now the media library and video windows are skinned too. I've also left in the old avs for all those people with winamp 2.xx
Fixed the old +12 -12 Db problem on the Equaliser 
The Text background colour is now the correct colour. Don't trust color reducing software!
Added Easter eggs!


Version 1.01 11/04/01
Cursors added. EQ bug fixed. Menu.cur also added. Grrr!

Got rid of the ugly radio tell-tale buttons on the main deck. It's so pretty now.

Version 1.0 29/03/01
Main winamp, Eq, Playlist, AVS and Minibrowser are skinned. No cursors. 

An original liquid crystal display set in blue steel finished grey radio buttons.
The display in an early version looked like cream.
However it didn't work under the constraints of winamp 2.XX
So the name SPILT MILK stuck.
I'm happy with it I hope you like it too.
