    This is  a  skin  for  WinAmp  v2.05  (x86).   The  Equalizer  and
Playlist  skins are not finished yet.   I will release them as soon as
possible.

    To install  this skin,  unzip it  into your Winamp  skins  folder.
(i.e.  "C:\Program Files\Winamp\Skins\")  Load up Winamp and go to the
Skin Browser dialog box by selecting the menu  or pressig ALT+S,  then
double-click on "Sonocaster".

Submit your questions, comments or suggestions to nexis@cyberspace.org
