==============================
MusicScoopAmp Installation
==============================

Extract the contents of the ZIP to a directory called
"MusicScoop" in your WinAMP skins directory.

(EX. C:\Program Files\Winamp\Skins\MusicScoop)

==============================
MusicScoopAmp Optimal Settings
==============================
Note:  Visualization settings can be found in 
"Visualization" in your main WinAmp menu.

*Set "Oscilloscope Scaling" to 0.5x 
(for best visualization)
*Set "Spectrum Analyzer" to "Lines"
(for optimal display)
